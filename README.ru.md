# Skill Router

Плагин для Claude Code: на каждый запрос и на каждую фазу работы находит подходящие скиллы и скиллы-наборы, показывает их Claude, а в режиме по умолчанию задерживает первое изменение, пока не вызван скилл. Мелкие правки не блокируются, повторно не блокируется ничего.

## Зачем

Когда скиллов сотни, Claude Code не может показать все описания: список обрезается, начиная с редко используемых, а скилл без описания почти не выбирается. Фраза «проверь все скиллы» не помогает: проверять уже нечего. Принудительный вызов на каждом ходу даёт ритуальные вызовы, которые только тратят время.

Skill Router ищет по **полному** набору скиллов сам, в хуке, и отдаёт Claude короткий ранжированный ответ. Вызов скилла требуется только при сильном совпадении.

## Что происходит на каждом запросе

1. Ранжирование установленных скиллов (личных, проектных, из плагинов) по имени, описанию и вашим синонимам. Скиллы, которыми вы пользуетесь, поднимаются; предложенные много раз и ни разу не вызванные постепенно слабеют, до половины.
2. Уровни: сильные совпадения (до четырёх) с причиной в одну строку и связанные скиллы только по имени. Подсказка короче 1,8 КБ.
3. Один-два набора скиллов: встроенные (`business`, `orchestration`, `web-design`, `debugging`, `research`, `writing`, `growth`, `learning`, `media`, `automation`), каждый плагин с тремя и более скиллами, семейства по имени (`founder-*`) и ваши собственные.
4. Фаза работы (plan, build, verify, ship). Закреплённые за фазой скиллы добавляются, а при смене фазы Claude выполняет `skill-router phase <имя>`, и проверка открывается заново.
5. Русский язык: встроенный словарь переводит частые слова задач в термины описаний скиллов, а `/skill-router:setup` обучает сопоставитель вашим словам.

## Режимы

| Режим | Подсказки | Задержка изменений |
|---|---|---|
| `off` | нет | нет |
| `suggest` | на каждую задачу | нет |
| `guided` (по умолчанию) | на каждую задачу | один раз за фазу, только при сильном совпадении, никогда на мелких правках |
| `strict` | на каждую задачу | пока не вызван скилл, до трёх раз за фазу; мелкие правки всё равно не блокируются |

Чтение (`ls`, `git status`, `grep`) проходит всегда. Выйти из задержки можно скиллом `skill-router:none-fits` с причиной в одну строку. Субагенты не блокируются, скилл, набранный вручную (`/frontend-design`), считается вашим выбором.

## Установка

```
/plugin marketplace add Shahriyor272011/claude-skill-router
/plugin install skill-router@skill-router
```

Затем один раз `/skill-router:setup`: плагин расспросит, чем вы занимаетесь, выберет режим, обучит сопоставитель вашей лексике, закрепит скиллы за фазами и создаст ваши наборы.

Нужны Claude Code 2.1.271 и новее и `python3` (только стандартная библиотека, сеть не используется).

## Приватность

Всё хранится на вашем компьютере. Журнал содержит имена скиллов, фазы и события, но не тексты запросов; отключается командой `skill-router profile set journal false`.

## Ограничения

Сопоставление лексическое, по описаниям. Словарь покрывает частые русские слова, остальные языки подключаются через синонимы. Определение намерения эвристическое. Не проверялось на Windows. Проверено: 57 модульных тестов, точки входа хуков с настоящим JSON Claude Code, реальный процесс Claude Code с загрузкой плагина и хуком запроса.
